- 筛选部分，后端已经提供了`/api/v1/all-keywords` 接口，来提供所有关键字 ：

  - **用例**

    - 构建关键词筛选器；
    - 展示知识库使用过的关键词总览；
    - 为输入框提供关键词建议。

    **鉴权**：不需要。

    **cURL 用例**

    ```bash
    curl "$API_BASE/all-keywords"
    ```

    **成功响应：200**

    ```json
    {
      "total": 3,
      "keywords": ["Excel", "Office", "WPS"]
    }
    ```

    **聚合规则**

    - 数据来自条目的规范化 `keywords_list`，不是原始 Markdown `keywords` 文本；
    - 范围覆盖所有文章下的全部条目；
    - 先剥离首尾空白，再按完全相同的文本去重；
    - `Flutter` 和 `flutter` 大小写不同，视为两个关键词；
    - 空关键词不返回；
    - `total` 等于去重后 `keywords` 数组长度；
    - 数组按 PostgreSQL 当前排序规则排列；
    - 接口不分页，一次返回全部去重关键词。
