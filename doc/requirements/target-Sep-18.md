## 功能更新

**Wiki模块的文章增加按钮功能需要实现**

1. 请参考`\doc\api`中的接口文档。

2. 点击添加按钮，首先会弹出登录界面，登录界面设计大致如：

   ```text
   ┌─────────────────────────────────────┐
   │
   │            Wiki的图标
   │                                     │
   │             Wiki                    │
   │                                     │
   │          登录您的账号                 │
   │                                     │
   │                                     │
   │  ┌───────────────────────────────┐  │
   │  │  输入用户名                    │  │
   │  └───────────────────────────────┘  │
   │                                     │
   │  ┌───────────────────────────────┐  │
   │  │  输入密码                      │  │
   │  └───────────────────────────────┘  │
   │                                     │
   │              忘记密码？（功能暂不实现）│
   │                                     │
   │  ┌───────────────────────────────┐  │
   │  │           下一步               │  │
   │  └───────────────────────────────┘  │
   │                                     │
   │                                     │
   │                                     │
   └─────────────────────────────────────┘
   ```



3. 登录如果错误，请在输入密码框底下显示：`ⓘ 账号或密码错误。请再试一次` 红色字体显示。

4. 如果连续登录次数错误超过5次，则禁止登录15分钟。

5. 登录成功后，跳转至增加文章增加功能。

6. 登录成功后，认证保留时间为1小时，过了1小时后，将自动下线。如果强制退出应用，认证不会保留。

**跳转的文章增加功能：**

1. 设计上为卡片形式，总共6张卡片：

   1. Question：cn=问题标题
   2. Description：cn=具体描述
   3. Causes：cn=产生原因
   4. Solutions：cn=解决方案
   5. Reviews：cn=复盘
   6. Keywords：cn=关键字
   7. Commit：cn=总览

2. 卡片布局设计大致为：

   ```text
   ┌─────────────────────────────────────----
   │            卡片名称                     |│
   │ ---------------------------------------- |
   │    ┌───────────────────────────────┐     │
   │    │  请输入内容...                  |     │
   │    │                               |     |
   │    |                               |     │
   │    |                               |     │
   | << |                               |  >> |
   |    |                               |     |
   |    |                               |     |
   |    |                               |     |
   |    |                               |     |
   |    |                               |     |
   |    |                               |     |
   |    |_______________________________|     |
   |                                          |
   |                                          |
   |__________________________________________|
   ```

3. 卡片名称为各个类的cn属性，如Question.cn，即问题标题。

4. 卡片可以通过左滑和右滑切换。

5. 点击输入内容框，除了弹出系统键盘以外，系统键盘上方会出现一个长椭圆型，布局大概是：

   ```text
   (_B_{code}_有序列表按钮__无序列表按钮_相机按钮_____)
   ```

   - B按钮：对应的是文本的加粗功能
   - {}按钮：对应的添加代码块功能
   - 有序列表按钮：对应的添加有序列表
   - 无序列表按钮：对应的是添加无序列表
   - 相机按钮：对应的是打开系统相机

   它们的功能都是为修饰和添加内容，内容的格式是Markdown格式。

6. Keywords页面，提供的是选择按钮，可以选择当前存在的Keyword，可以多选。

7. Commit页面为最后一页，它的效果是Wiki功能显示一篇文章一样，显示待添加的文章内容。

   1. 它的文本框可以直接编辑。
   2. 它的末尾有两个按钮，一个是√，一个是×。
   3. 点击√或×，都会有再此确认的提示；
      - √提示：确认提交？
      - ×提示：删除草稿？
   4. 点击√：
      - 如果成功：弹出消息提示，提交成功，并返回Wiki功能的主页。
      - 如果失败：弹出消息提示，停留在当前页面。
   5. 点击×：
      - 它必须成功：弹出消息提示，提交成功，并返回Wiki功能的主页。
