# Oct-15 更新说明：神机资产搜索

## 需求与范围

按 `doc/requirements/target-Oct-14.md`、`doc/ui/iadb/iadb_ui.html` 和更新后的 `doc/api/神机-API.md` 实现。根据用户确认，使用 `http://159.75.86.98:10001` HTTP API，不连接数据库端口。

本次实现独立登录、资产搜索与分页、资产关联详情、IP/MAC 复制及主页入口。设计稿中的排序、导出、Ping、SSH、测速和索引管理不在此次范围内。

## 使用方式

1. 打开主页「神机」，输入神机账号及密码；Wiki 登录不受影响。
2. 输入 IP、MAC、人员、部门或设备等关键词，点击搜索或键盘搜索键。
3. 在「资产」与「命中记录」之间切换；每页请求 20 条，通过上一页/下一页浏览。
4. 点击 IP/MAC 行复制；点击「查看详情」展开资产、网卡、IP、关联关系和历史等实际返回字段。
5. 右上角退出按钮清空本地会话并请求服务端注销。关闭进程后需要重新登录。

## 代码实现

- 新增 `lib/features/iadb/`：Models 负责响应校验，Repository 负责认证和检索，ViewModel 管理会话、刷新与查询，View 展示登录、结果卡片及详情。
- 默认地址由 `IADB_API_BASE_URL` 编译变量覆盖，调用 `ApiClient.requestJson` 支持 JSON 请求、Bearer、204 与统一错误提示。原 Wiki HTTP 方法保持原有行为。
- 令牌只存内存，不持久化密码或令牌；刷新时替换两种令牌，并发刷新复用请求。401 最多重试一次；刷新认证失败回到登录状态。
- 搜索响应的资产和原始记录独立展示及计数，避免遗漏没有关联资产的发现记录。详情直接使用搜索上下文，未知关联字段也可展开阅读。
- 清空、退出与离开页面会清理检索状态；旧响应不会覆盖已清空的页面。退出失败会明确说明本地已退出而服务端撤销未成功。
- 神机保持原 `smart` 标识并补全路由，常用工具配置兼容；功能搜索注册表同步加入神机。
- 界面复用 BusyBoxPalette，支持深色模式、窄屏、空结果、加载、错误重试及分页边界。请求耗时是客户端实测值，不使用设计稿示例数字。

## 已知边界

- 本轮未构建 APK，未进行 Android 真机操作验证。
- API 文档当前声明无 CORS 支持；Web 跨域访问需后端配置。HTTPS 网页不能直接依赖 HTTP 后端，部署时需要 HTTPS 服务或同源代理。
- 详情展示的是本次搜索快照；再次搜索可获取最新数据。
- 当前地址使用用户指定的 HTTP；生产环境传输登录凭据应配置 HTTPS。
