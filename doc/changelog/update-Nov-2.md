# Nov-2 更新说明

## 范围

依据 `target-Nov-2.md` 和 `ai/prompt.md` 实现 Ping。用户确认 Android 优先，真实 ICMP；TTL 1000ms 改为“超时1000ms”；历史本机保存，导出先复制诊断文本。参考页面保存在 `doc/ui/ping/ping-home.html` 和 `ping-result.html`。

## 功能

- 主页 Ping 入口、常用工具及搜索接入 `/ping`；结果页为 `/ping/result`，无参数直接打开时提示先设置目标。
- 输入1–4个不同的IPv4或域名，包大小1–1472字节、次数1–100、超时100–10000ms。默认64字节、4次、1000ms，目标之间并行，同一目标顺序探测，默认起始间隔至少1秒（超时更长时不重叠发包）。
- Android调用 `/system/bin/ping`，使用参数数组而非shell拼接。目标校验拒绝参数注入；单次超时后终止进程。其他平台明确提示暂不支持，不以HTTP代替ICMP。IPv6输入本轮不支持。
- 每目标实时显示发送/接收、丢包、平均/最小/最大延迟及总体标准差Mdev。折线图使用实际采样时刻，丢包处断线和红点，不将超时记为0ms。点击图表查看最近一次探测。
- 支持停止、重新测试、复制当前诊断摘要；离页释放Provider和进入后台会停止。重启与销毁通过会话序号隔离旧响应。
- 已完成的测试保存本机最近50次记录，支持清空；停止的部分结果保留在当前页，不写入完成历史。历史读写失败显示提示。
- 沿用明暗色板、圆角卡片、双列指标；不填充虚构“网络就绪”、网关别名、示例历史或优良等级。

## 后期扩展

可通过 PingTransport 接入其他原生平台或IPv6；扩展平台时需要提供真实探测并验证命令参数与输出。不可将TCP/HTTP耗时标为ICMP往返时延。

## Nov-3 设计细节复核

历史记录改为每目标独立卡片，标题下面显示相对时间及实际参数，底部显示 YYYY-MM-DD HH:mm:ss，兼容旧记录缺少包大小的情况。平均延迟和丢包率改为并排灰底信息块；0%丢包使用主题状态绿，有丢包为红色，未知为灰色，不再全部显示品牌蓝。结果页收发数量使用正文色、平均延迟使用蓝色。卡片圆角调整为12px、间距10px，标题18px，参数在正常手机宽度保持三列，开始按钮高度48px。新增历史时间位置与零丢包配色回归测试。
